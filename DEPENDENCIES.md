# Dependencies

- fonttools: upstream UFO and TR font file readers/writers.
- hatchling: PEP 517 wheel and source distribution builder.
- hatch-vcs: Git tag-derived versions, with source archive metadata support; also used in isolated Git regression tests.
- pytest: packaging and standalone geometry regression checks.
- build: optional isolated PEP 517 frontend for development.
